# Как выложить новую версию

Exe **не нужно** загружать руками. GitHub сам соберёт его из исходников и положит в Releases.

## Почему exe не в файлах репозитория

GitHub хранит код, а не программы. Бинарник в репозитории:

- раздувает историю (каждая версия = +12 МБ навсегда)
- ломает diff и ревью
- не даёт понять, из какого кода он собран

Поэтому exe живёт в **Releases** — отдельном разделе, где GitHub хранит собранные файлы. Это стандарт для всех проектов.

Ссылка на скачивание всегда одна и не меняется:

```
https://github.com/artikgor2014-star/potato-chat/releases/latest/download/PotatoChat.exe
```

Она всегда ведёт на последнюю версию.

## Выпустить новую версию — 1 клик

1. Открой https://github.com/artikgor2014-star/potato-chat/actions
2. Слева выбери **Build and release**
3. Справа кнопка **Run workflow**
4. В поле версии впиши `1.0.2` (без буквы v)
5. **Run workflow**

Через 3–4 минуты:

- соберётся exe из кода в репозитории
- создастся тег `v1.0.2`
- появится релиз с файлами `PotatoChat.exe` и `SHA256SUMS.txt`
- на сайте сам обновится версия и хеш

Ничего качать и загружать не надо.

## Что происходит внутри

```
src/                    исходники
  ↓ pnpm install
  ↓ wails3 generate bindings
  ↓ wails3 build
bin/potato-chat.exe     собранный бинарник
  ↓
Releases v1.0.2         публикация
  ↓
index.html              обновление хеша и номера версии
```

## Если менял код

Обычный git:

```bash
git add -A
git commit -m "что изменил"
git push
```

Затем запусти workflow как выше. Тег и релиз создадутся сами.

## Если хочешь старую версию

Releases → выбери нужный тег → скачай `PotatoChat.exe`. Все версии остаются доступны навсегда.

## Проверка после публикации

```bash
curl -sL https://github.com/artikgor2014-star/potato-chat/releases/latest/download/SHA256SUMS.txt
```

Сверь с файлом:

```
certutil -hashfile PotatoChat.exe SHA256
```

Хеши должны совпасть. Это доказывает, что скачанный файл не подменён.

## Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| «Файл не поддерживается» при загрузке exe | пытаешься положить бинарник в файлы репозитория | не надо, используй Releases |
| Workflow упал на `pnpm install` | изменился `pnpm-lock.yaml` | запусти `pnpm install` локально и закоммить lock |
| Workflow упал на `wails3 build` | сломался Go-код | проверь локально `wails3 build` в `src/` |
| Сайт показывает старую версию | Pages деплоится 1–2 минуты | подожди, потом Ctrl+F5 |
